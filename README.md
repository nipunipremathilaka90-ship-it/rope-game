# Rope Game 🎮

## About the Project
Rope Game is an interactive browser-based game developed using HTML, CSS, and JavaScript.

## Features
- Simple and attractive user interface
- Interactive gameplay
- Easy to play
- User-friendly design

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Enjoy playing the game!
